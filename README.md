# Hidrocarbo

Juego educativo para aprender a nombrar hidrocarburos (alcanos, alquenos, alquinos, cicloalcanos y aromáticos).

- Pestaña **Aprender**: prefijos, familias y ejemplos dibujados.
- Pestaña **Jugar**: 5 preguntas, con nota sobre 5,0. La nota mínima para aprobar es 3,0.

Es un solo archivo (`index.html`), sin instalación. Ábrelo en el navegador o publícalo con GitHub Pages.
